## 实际界面

在原来准备使用这款字体的系统界面和应用中检查：

1. 设置列表、通知、弹窗、按钮和输入框的行高、上下留白是否正常，是否出现裁切、重叠或缺字。
2. 常规文字和粗体是否使用了正确字重。应用支持选择可变字重时，补看 200、300、400、600、700、900；无法设置的项目注明“应用不提供控制”，不要填作通过。
3. 检查逗号、分号及附加符号：`LY GT Go ,; G̀́`。留意粗体、斜体下的明显横向偏移或碰撞。
4. 检查数字与冒号：`0123456789 09:41 1:2 1: :2 a:2 ķ:2 ș:2`。数字默认比例宽；数字旁的冒号遵循 Inter 上浮规则，小写字母旁应保持原位。
5. 检查中文标点与中西文混排：`中文……继续——检查———结束`、`Loading… A—B A——B`、`⸺ ⸻`。记录具体应用与系统语言，应用可能为同一段文字选择不同的文字系统或语言。
6. 如果目标应用支持竖排，检查 `甲……乙——丙⸺丁` 和 `甲……乙———丙⸻丁`：长破折号应连续，不侵入前一个字的格子，两个省略号占两个字格。
7. 如果应用提供 OpenType 特性设置，分别检查 `tnum`、`pnum`、`tnum + zero`；等宽数字和斜线零应严格对齐。记录 `chws/vchw` 是自动开启、手动开启，还是应用未提供支持。
